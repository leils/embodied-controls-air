Settings

Viewer

Hide the camera image and show left and right panels with four finger segments across the top (index through pinky). Pinch turns the panel yellow. A thumbs-up adds a glowing edge when not pinching.

Channels

Shared by Individual channels and Bank channels.

Range 1 to 1000. Default 250. How much the selected channel changes when your right index fingertip moves up or down in the camera. Up raises the channel, down lowers it. A higher number means the same fingertip travel changes the value more. The channel stops at Min and Max.
Range 0 to 127. Default 0. The lowest value any channel can hold. Moving your right index fingertip down will not push a channel below this. A channel already under it is raised to this number.
Range 0 to 127. Default 127. The highest value any channel can hold. Moving your right index fingertip up will not push a channel above this. A channel already over it is lowered to this number.
Range 0 to 0.1, as a fraction of the picture height. Default 0.003. If your right index fingertip moves less than this from one moment to the next, the channel stays put. Raise it when a still hand makes the value jitter. Lower it when small deliberate moves do nothing.

Pinch

Range 1 to 1000. Default 250. How much the channel changes when the gap between your two pinched index fingertips grows or shrinks. A wider gap raises the value, a narrower gap lowers it. A higher number means the same change in that gap moves the channel more. The value stays between 0 and 127.

Gesture tester

While it runs, hand input goes to the tester and no MIDI is sent. Close both fists, open, then close again within 1 second. Hold your palms flat together. Or give a thumbs up or thumbs down with either hand.
