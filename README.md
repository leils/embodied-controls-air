# Embodied Controls - AiR program, Exploratorium 

Web tests for various mediapipe + midi controls, for Artist in Residence James Sprang (2026). 
Project goals: 
- To create a gestural MIDI controller for artist use, inputting physical gestures & outputting MIDI for integration with Ableton. 
- Allow the artist to move in the ideal workflow of "record -> edit -> choreograph" while minimizing the use of screens 

These tests are on the majority AI-generated with guidance; they are **not** considered production ready, and should be re-written & checked before full use.
